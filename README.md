# User Behaviour Analysis using Isolation Forest

This project presents an interactive Streamlit application that analyzes user activity data and detects anomalous behaviour patterns using an unsupervised machine learning model.

The system is designed to simulate real-world use cases such as fraud detection, abnormal activity monitoring, and behavioural analysis.

## Features
- Upload CSV-based user activity datasets
- Automatic data cleaning, encoding, and scaling
- Anomaly detection using Isolation Forest
- Adjustable contamination rate
- Interactive visualizations including bar charts, pie charts, and scatter plots
- Export of processed data with anomaly labels

## Machine Learning Approach
- Algorithm: Isolation Forest
- Learning Type: Unsupervised Learning
- Purpose: Detect abnormal user behaviour without labelled data
